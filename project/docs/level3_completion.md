## 📋 题目设计

### 前15题（单一物品）
- 第1-6题：难度1，数量1-6
- 第7-15题：难度2，数量5-10
- 每题使用不同的装饰物类型

### 后20题（组合物品）
- 第16-35题：难度3
- 每题包含2种装饰物的组合
- 数量范围：2-10个
- 覆盖所有装饰物的多种组合方式

## 🎮 游戏机制

### 单一题目流程：
1. 族长出题（打字机效果）
2. 小孩回应
3. 点击小孩打开游戏弹窗
4. 选择装饰物类型
5. 点击绳子打结（绳结上显示装饰物图标）
6. 提交答案
7. 显示星级和鼓励语
8. 自动进入下一题

### 组合题目流程：
1. 族长出题（需要记录多种物品）
2. 打开游戏弹窗
3. 选择第一种装饰物
4. 在第一根绳子上打结
5. 选择第二种装饰物
6. 在第二根绳子上打结
7. 提交答案（验证所有绳子的装饰物和数量）
8. 显示结果

## 🚀 使用说明

### 1. 执行SQL
```bash
# 先执行关卡创建
mysql -u root -p project_db < project/sql/level3_game_level.sql

# 再执行题目插入
mysql -u root -p project_db < project/sql/level3_questions.sql
```

### 2. 前端编译
```bash
cd client_home
npm run build:mp-weixin
```

### 3. 后端重启
```bash
cd project
mvn clean package
java -jar target/demo.jar
```

## 🔧 可扩展性

### 添加新装饰物：
1. 在题库SQL中定义新的装饰物类型
2. 前端自动从题目内容中读取装饰物列表
3. 无需修改代码，只需更新题目数据

### 添加新题目：
1. 在 `question_bank` 表中插入新题目
2. 设置 `question_type` 为 `rope_decoration` 或 `rope_decoration_combo`
3. 设置 `question_content` 和 `correct_answer` 的JSON格式
4. 前端自动适配
